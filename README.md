# Barmuda Romverksted

Interaktiv plantegning og 3D-modell av Barmuda (Solsiden, Trondheim) for å prøve ut nye planløsninger: rive og tegne vegger, møblere med bar, bord og scene, og laste ned plantegning, møbelliste og planfil.

Åpne siden: https://jjameson90.github.io/Eiendom360-Barmuda-Romverksted/

**Grunnlag:** Matterport-skanning av lokalet (hovedrom 9,34 × 10,16 m) og Matterport-plantegning. Veggmål er normalt innenfor ±5 cm. Møbler, bar og to av søylene er anslått fra 360-bilder. Kontroller mål på stedet før bestilling og bygging.

**Deling av forslag:** Last ned planfilen (Forslag → Last ned som planfil) og send den videre. Mottakeren åpner den med Eksporter → Åpne planfil. Arbeidet lagres også automatisk i nettleseren.

Laget med Claude for Eiendom360.
